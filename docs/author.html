Motivasi

"Bisakah kita membuat bahasa pemrograman yang mudah dipelajari dan menggunakan sintaks dalam Bahasa Indonesia?"

Dari pertanyaan itu lahir Indonesiaku. Sebagai developer Indonesia, Teguh ingin membuat sesuatu yang bermakna: bahasa pemrograman yang menghapus hambatan bahasa bagi pelajar lokal, sekaligus menjadi wadah belajar mendalam tentang compiler design dan virtual machine.

Tujuan Proyek

  • Aksesibilitas — programming lebih mudah diakses pelajar Indonesia.
  • Pembelajaran — memahami lexing, parsing, code generation, dan GC.
  • Komunitas — membangun komunitas seputar bahasa lokal.
  • Inovasi — menunjukkan Indonesia bisa membuat teknologi berkualitas.

Filosofi Desain

  • Simple, but not simplistic — mudah untuk pemula, tetap powerful.
  • Indonesian first — keyword & dokumentasi dalam Bahasa Indonesia.
  • Educational — dirancang untuk mengajarkan konsep pemrograman.
  • Open source — semua orang bisa belajar dan berkontribusi.

Keahlian Teknis

  • Compiler design — lexing, parsing, code generation
  • Virtual machine — stack-based VM berbasis bytecode
  • Memory management — garbage collection & optimasi memori
  • Open source — kontribusi ke berbagai proyek
