Kenapa Indonesiaku?

Bahasa yang lengkap fiturnya, ditulis untuk belajar dan berkarya dalam bahasa sendiri.

🗣️

Keyword Bahasa Indonesia

jika, selagi, fungsi, kelas, cetak — kode yang terbaca alami.

🧠

Fitur Modern

Closure, list & kamus, kelas & pewarisan, exception, dan sistem modul.

♻️

Garbage Collector

Manajemen memori otomatis (mark-sweep) — fokus pada logika, bukan alokasi.

📇

JSON & REST API

Pustaka JSON & HTTP bawaan. Contoh Todo-list: CRUD CLI dan server REST.

📚

Pustaka Standar

Teks, daftar, matematika, kamus — ditulis dalam bahasa Indonesiaku sendiri.

⚡

Ringan & Cepat

Bytecode VM berbasis stack dalam C11. Image Docker ~12 MB.

Sekilas Kode

Kelas, pewarisan, dan penanganan kesalahan — semuanya dalam Bahasa Indonesia.

kelas Hewan {
    init(nama, suara) {
        diri.nama = nama
        diri.suara = suara
    }
    bersuara() {
        cetak(diri.nama, "berkata:", diri.suara)
    }
}

kelas Anjing < Hewan {          # pewarisan
    init(nama) { super.init(nama, "Guk") }
}

coba {
    Anjing("Rex").bersuara()    # Rex berkata: Guk
} kecuali e {
    cetak("gagal:", e)
}
