Tentang Indonesiaku

Indonesiaku adalah bahasa pemrograman yang dirancang agar programming bisa dipelajari dan dipakai dalam Bahasa Indonesia. Semua kata kunci — jika, selagi, fungsi, kelas, cetak — menggunakan Bahasa Indonesia, menghapus hambatan bahasa bagi pemula lokal.

Visi & Misi

Menjadi bahasa pemrograman yang membuka akses pendidikan programming untuk jutaan penutur Bahasa Indonesia — membuktikan bahwa bahasa pemrograman dapat didesain dengan keyword non-Inggris tanpa mengorbankan fitur.

Bagaimana Cara Kerjanya?

Indonesiaku diimplementasikan sebagai bytecode virtual machine dalam C11, mengikuti arsitektur ala Crafting Interpreters (clox): 

Kode Sumber (.idk)
     ↓  Scanner (lexer)
     ↓  Compiler single-pass (Pratt parser → bytecode)
     ↓  Virtual Machine berbasis stack + garbage collector
     ↓  Output

Fitur Utama (v0.4.0)

  • Tipe data: angka, boolean, string, kosong, list, kamus.
  • Kontrol alur: jika/jika_lain/selain, selagi, untuk ... dalam, hentikan/lanjut.
  • Fungsi: rekursi, closure (menangkap variabel), fungsi kelas-satu.
  • OOP: kelas, init, diri, pewarisan (<), super.
  • Kesalahan: naikkan, coba/kecuali.
  • Modul: impor "file.idk".
  • Pustaka standar: teks, daftar, matematika, kamus, JSON, HTTP.
  • Infrastruktur: garbage collector mark-sweep, File I/O, waktu/tanggal, soket TCP.

Contoh Aplikasi Nyata

Repositori menyertakan aplikasi Todo-list JSON DB dalam dua bentuk: CRUD berbasis command-line (examples/todo_cli.idk) dan REST API HTTP server (examples/todo_server.idk) — keduanya diuji otomatis di CI lintas Linux, macOS, dan Windows.
