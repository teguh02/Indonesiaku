Motivasi

“Bisakah kita membuat bahasa pemrograman yang mudah dipelajari dan menggunakan sintaks dalam Bahasa Indonesia?”

Dari pertanyaan itu lahir Indonesiaku. Sebagai developer Indonesia, Teguh ingin membuat sesuatu yang bermakna: bahasa pemrograman yang menghapus hambatan bahasa bagi pelajar lokal, sekaligus menjadi wadah belajar mendalam tentang compiler design dan virtual machine.

Tujuan proyek

  • Aksesibilitas
    programming lebih mudah diakses pelajar Indonesia.
  • Pembelajaran
    memahami lexing, parsing, code generation, dan GC.
  • Komunitas
    membangun komunitas seputar bahasa lokal.
  • Inovasi
    menunjukkan Indonesia bisa membuat teknologi berkualitas.

Filosofi desain

  • Simple, but not simplistic — mudah untuk pemula, tetap powerful.
  • Indonesian first — kata kunci dan dokumentasi dalam Bahasa Indonesia.
  • Educational — dirancang untuk mengajarkan konsep pemrograman.
  • Open source — semua orang bisa belajar dan berkontribusi.

Keahlian teknis

  • Compiler design — lexing, parsing, code generation.
  • Virtual machine — stack-based VM berbasis bytecode.
  • Memory management — garbage collection dan optimasi memori.
  • Open source — kontribusi ke berbagai proyek.

Motivation

“Can we build a programming language that is easy to learn and uses Indonesian syntax?”

Indonesiaku was born from that question. As an Indonesian developer, Teguh wanted to build something meaningful: a language that removes the language barrier for local students, while also becoming a deep learning ground for compiler design and virtual machines.

Project goals

  • Accessibility
    programming becomes easier to reach for Indonesian students.
  • Learning
    understand lexing, parsing, code generation, and GC.
  • Community
    build a community around a local language.
  • Innovation
    show that Indonesia can build quality technology.

Design philosophy

  • Simple, but not simplistic — approachable for beginners, still powerful.
  • Indonesian first — keywords and documentation in Indonesian.
  • Educational — designed to teach programming concepts.
  • Open source — everyone can learn and contribute.

Technical skills

  • Compiler design — lexing, parsing, code generation.
  • Virtual machines — stack-based bytecode VMs.
  • Memory management — garbage collection and memory optimisation.
  • Open source — contributions across projects.
