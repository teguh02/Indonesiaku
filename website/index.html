02 — Sekilas kode

Kelas, warisan, dan error handling

Kata kunci Indonesia yang konsisten.

  • 1 init sebagai konstruktor.
  • 2 Pewarisan memakai <.
  • 3 naikkan dan coba/kecuali.
kelas.idk 
kelas Hewan {
    init(nama, suara) {
        diri.nama = nama
        diri.suara = suara
    }

    bersuara() {
        cetak(
            diri.nama, "berkata:",
            diri.suara
        )
    }
}

# Pewarisan dan konstruktor turunan
kelas Anjing < Hewan {
    init(nama) {
        super.init(nama, "Guk")
    }
}

coba {
    Anjing("Rex").bersuara()
} kecuali e {
    cetak("gagal:", e)
}
